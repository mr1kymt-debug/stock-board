    データを読み込む

    パソコンで stock_screener.py を実行すると出来る screener_result.csv を読み込むと、実際のスコアと1か月後の見立てに切り替わります。ニュースの news_view.json も同じ方法で読み込めます。読み込んだデータは保存され、次回以降もこのページに表示されます。

    ファイルが使いにくいときは、中身をここに貼り付けてください。

    点数や「頭打ち注意」などの判定は、同じ市場の中での比べ合いです。総合スコアは、上昇の勢い75%と、頭打ちしにくさ25%で決めています。「1か月後の見立て」は、これに直近のニュースと市場全体の状況を加えた目安で、株価の範囲は過去1年の値動きの大きさから計算しています。ニュースはウェブの報道をもとにClaudeが要約したもので、間違いを含む可能性があります。投資判断の補助用の参考情報で、将来の値上がりを保証するものではありません。
